# Project 3 - viscous airfoil

The personal [Roohi-code source](roohi-code/Viscous/airfoilla%20V%20LAST.for) declares three-/four-face connectivity arrays, separate `connectivity1.DAT` and `connectivity2.DAT`, and viscous flux fields. Its `Input` routine sets `RE=1.D3`, `XMIN=1.2D0`, and zero angle of attack; these values describe this particular archived variant.

Matching node, connectivity and boundary input files are preserved in the same [Viscous directory](roohi-code/Viscous). `NEIB.DAT`, `NEIGHBOUR.DAT`, residuals and visualization files are generated by the source, so old generated copies are not mixed into the input set. The [quantity variant](roohi-code/airfoilla%20QUANTITY.for) is archived separately.

[Original report](../../reports/03-viscous-airfoil/Report%203.doc). Source from other named collaborators' folders is not silently attributed to Roohi; the published selection comes from the personal Roohi-code/My-Grid branches.
