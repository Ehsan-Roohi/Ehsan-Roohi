# Provenance and archive policy

- Personal projects: local `CFD 2` folder, identified by Ehsan Roohi as coursework for Dr. Mazaheri.
- Hejranfar lectures: local `CFD 2 Hejranfar`; the seven chapter title pages identify Kazem Hejranfar, Sharif University of Technology. The additional scanned chapter is attributed to the source folder.
- Van Leer supplements: local `Van Leer Notes`; the course outline identifies Bram van Leer and AE 520 Fall 2011. The gas dynamics cover additionally identifies Peter Bakker (Delft), AE4-140, February 21, 2005. The PDF named `lecturenotes2DSSBurgers.pdf` begins with an AE 520 Fall 2011 exam; its original filename is retained, but its contents are labeled from visual inspection.
- RWTH Aachen supplement: eleven lecture PDFs and one syllabus extracted from `CFD Achen/artifacts.zip`; title and instructors checked against `CFD Achen/mssd-main.zip` README and PDF opening pages.
- External code review: `jyoun35/SIMPLE`, pinned commit `6a1d90684c9462aa48416894f147910ca20e238f`. Reviewed source is linked rather than copied into this collection.

Each copied original is listed in `manifest.json` with its original relative path, byte size and SHA-256. The copy process does not rewrite text encodings or line endings. `tools/verify_archive.py` checks those bytes and local Markdown links.

A curated selection preserves distinct personal source variants and five Project 2 cases, not every duplicate/build/output in the local folders. Executables, object/debug files, IDE state, redundant ZIPs, publisher-paper caches and other collaborators' code folders are not part of this selection. Existing source files and lecture documents keep their original authorship and reuse terms; no new blanket license is assigned to them.

The original local Project 1 cover/report `CFD 2/project 1/Geld.doc` explicitly names Dr. Mazaheri and Spring 1386 (Persian calendar), corroborating the user's course identification. Mazaheri's official syllabus and independent lecture files have not yet been located. This publication does not relabel Hejranfar slides as Mazaheri slides.
